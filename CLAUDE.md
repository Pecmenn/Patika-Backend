# Patika Backend

Patika telefon uygulamasının sunucusu. Uygulama `Desktop\Patika-App` klasöründe, kararlar ve kapsam oradaki `PROJE-PLANI.md` dosyasında.

Kullanıcı yazılımcı değil ve yaparak öğrenmek istiyor. Türkçe konuş, ne yaptığını ve nedenini sade dille anlat, teknik terimi ilk geçtiği yerde tanımla.

Mimari ve komutlar: `README.md`.

- Kod değişince `npm run typecheck` ve `npm test` çalıştır. Kayıp sayfası değiştiyse `npm run test:page`.
- Uç eklerken başka kullanıcının veriye ulaşamadığını sınayan test de ekle.
- `.env` içindeki parolaları sohbete yazma.
